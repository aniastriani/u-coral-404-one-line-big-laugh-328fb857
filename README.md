One sentence, one joke. A smart fridge rats me out to my doctor over
midnight snacks — and the punchline is that my leftovers end up with
better healthcare than I do.

> "My smart fridge emailed my doctor about my midnight snacks, so now my leftovers have a better healthcare plan than I do."

A small deterministic Python program writes exactly that line — 120
characters, no trailing newline — to `/output/entry.txt`. Run it twice
and the bytes are identical.

## Why this line

The setup sounds like an ordinary smart-home complaint, then the turn
hands the good life to the wrong party: not me, not the fridge — the
leftovers. Three beats, one sentence, nothing wasted.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/output python3 main.py
```

`main.py` is the packed entrypoint, compressed from the readable
`source.py` with `makefun compress`. Standard library only: no
dependencies, no network, no randomness.
